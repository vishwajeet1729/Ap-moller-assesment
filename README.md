# 🧠 GenAI E-Commerce Insights Assistant (C++ Dummy Demo)

This project is a **lightweight GenAI-style analytics assistant** built entirely in **C++**.  
It simulates how a real NL→SQL GenAI system would answer business questions on an e-commerce dataset.

✅ Single-file implementation  
✅ Large dummy dataset (60+ realistic ecommerce rows)  
✅ Natural language → SQL-like logic  
✅ Aggregation engine (revenue, AOV, statewise orders, category counts)  
✅ Perfect for demo videos, assignments, and interviews
